
# DevOps Learning Lab

A beginner-friendly project for learning Git, GitHub,
Linux, and DevOps fundamentals.

## Project Features

- Display Linux system information
- Check root filesystem disk usage
- Practice Git commits and pushes
- Document useful Git commands

## Requirements

- Linux
- Bash
- Git

## How to Run

Make the script executable:

```bash
chmod +x scripts/system-info.sh
```

Run the script:

```bash
./scripts/system-info.sh
```

## Learning Goals

- Understand Git repositories
- Practice branches and commits
- Push changes to GitHub
- Learn basic Linux automation
