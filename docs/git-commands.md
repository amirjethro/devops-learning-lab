
# Git Commands Cheat Sheet

## Check repository status

```bash
git status
```

## Stage changes

```bash
git add .
```

## Commit changes

```bash
git commit -m "Describe your changes"
```

## Push changes

```bash
git push
```

## View commit history

```bash
git log --oneline
```

## View configured remotes

```bash
git remote -v
```
